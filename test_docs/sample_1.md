# Introducción a Go

Go es un lenguaje de programación de código abierto compilado y tipado estáticamente diseñado por Google. Se enfoca en la simplicidad, la eficiencia y el soporte integrado para la concurrencia.

# Goroutines

Las goroutines son funciones o métodos que se ejecutan simultáneamente con otras funciones o métodos. Son extremadamente ligeras y requieren muy poca memoria inicial.

# Canales

Los canales (channels) son la forma en que las goroutines se comunican entre sí y sincronizan su ejecución. Permiten enviar y recibir valores de un tipo específico.

# Interfaz

En Go, las interfaces proporcionan una forma de especificar el comportamiento de un objeto: si algo puede hacer *esto*, entonces puede usarse *aquí*. Son implementadas implícitamente.
